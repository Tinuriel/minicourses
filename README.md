# Мини-курсы

Навык для Claude Code, который превращает любую тему в короткий текстовый курс с собственным сайтом.

```
> сделай мини-курс по переговорам о зарплате
```

Claude ищет и читает 20–40 хороших источников, выясняет, в чём они согласны и где спорят, составляет план и пишет **один пробный урок**. Вы смотрите его на сайте курса. Если формат нравится, Claude пишет остальные уроки по тому же образцу и собирает сайт целиком, готовый к публикации.

Навык основан на [Claudemy](https://github.com/assafkip/claudemy) Ассафа Кипниса (MIT) и переработан:

- **без аудио**: вместо диалогов двух ведущих — структурированный текст;
- **грамотный язык**: уроки пишутся сразу на языке курса (по умолчанию русском) по подробному руководству по стилю, а проверка ловит типичные признаки перевода — кальки, прямые кавычки, дефисы вместо тире, Заглавные Буквы в заголовках, смешение «ты» и «вы»;
- **сайт курса**: статические страницы, которые можно открыть с диска или выложить на любой хостинг.

## Из чего состоит урок

Каждый урок читается за 3–6 минут и устроен одинаково:

1. **Коротко** — три пункта, суть урока.
2. **Разбор** — одна идея, объяснённая связным текстом.
3. **Пример** — одна конкретная ситуация от начала до конца.
4. **Что говорят источники** — сколько источников согласны и кто спорит.
5. **Попробуйте** — небольшая практика на 2–30 минут с готовыми шагами.
6. **Правило** — одно предложение, которое стоит оставить себе.
7. **Проверьте себя** — 2–4 вопроса с ответами, которые открываются по клику.
8. **Почитать подробнее** — ссылки на реальные страницы, которые прочитали при подготовке курса.

## Сайт курса

- Главная: описание, части курса, все запланированные уроки (ненаписанные помечены «Скоро»), прогресс, «Где источники расходятся».
- Страница для каждого урока с навигацией «назад/дальше» и отметками «Прочитано», «Попробовано».
- «Мои правила» — правила всех уроков: отметить свои и распечатать.
- «Источники» — все прочитанные страницы и уроки, в которых они упоминаются.
- Светлая и тёмная тема, удобно с телефона, можно печатать.
- Никаких внешних шрифтов, скриптов, трекеров и cookies; отметки хранятся только в браузере читателя.

Каждая страница — самодостаточный HTML-файл: работает с диска, на GitHub Pages, Netlify, Render, Cloudflare Pages или как страница claude.ai.

## Публикация в этом репозитории

Папка `docs/` — каталог курсов для GitHub Pages:

```bash
python3 skills/minicourse/scripts/build_site.py minicourse/<slug> --out docs/<slug> --catalog ../
```

```bash
python3 skills/minicourse/scripts/build_catalog.py docs
```

После пуша курс будет по адресу `https://tinuriel.github.io/minicourses/<slug>/`. GitHub Pages включается один раз: Settings → Pages → Deploy from a branch → ветка `main`, папка `/docs`.

Рабочие папки курсов (`minicourse/`) и скачанные страницы (`raw/`) в репозиторий не попадают: это чужие тексты для внутреннего пользования.

## Установка

Как плагин Claude Code:

```
/plugin marketplace add Tinuriel/minicourses
/plugin install minicourse@minicourses
```

Или скопируйте папку `skills/minicourse/` в `~/.claude/skills/`.

## Что нужно

- Claude Code с веб-поиском.
- Python 3 и `beautifulsoup4` (`pip install beautifulsoup4`) для загрузки страниц. Сборка сайта и проверка уроков работают на одной стандартной библиотеке Python.

## Скрипты

| Скрипт | Что делает |
|---|---|
| `scrape.py` | скачивает страницы из `sources.json` в `raw/` |
| `check_lessons.py` | проверяет структуру уроков, ссылки на источники и стиль |
| `build_site.py` | собирает сайт курса |
| `build_catalog.py` | собирает страницу-каталог из нескольких курсов |

Тесты: `python3 -m unittest discover -s tests`.
