# Бриф карты согласия: все заметки → темы с подсчётом согласия

Этот файл получает один агент, который строит карту согласия.

## На входе
- Все заметки: `<workspace>/research/notes/*.md`. Номера вида `a:N12`.
- Коды подтем: `<workspace>/research/topics.md`.

## Что такое тема
Одна идея, которой можно научить, записанная как совет: «Называйте точную сумму, а не круглую», а не «якорение». 30–45 тем. Две идеи, которые тянут в разные стороны, — это две темы, и разногласие записано у обеих. Пишите на языке курса.

Одна заметка может поддерживать несколько тем; укажите её под каждой.

## Подсчёт согласия: N из M
- **M** — число разных страниц (url), у которых есть хотя бы одна заметка по подтеме этой темы, включая строки `Also:`. Это источники, у которых была возможность это сказать.
- **N** — сколько из этих M страниц поддерживают тему.
- Считаются страницы, а не заметки: три заметки с одной страницы — один источник.

«9 из 14» значит: 14 страниц касались этого вопроса и 9 из них учат этой идее. Тема с M меньше 3 помечается «мало данных».

## Для каждой темы
```
## TH07 <идея как совет>
- Подтема: T03 (также T07)
- Согласны: N из M. Заметки: a:N3, c:N12 … Url: <каждый поддерживающий url один раз>
- Против: <url>: <их позиция в одну строку> или «не найдено»
- Уровень: основа | главное | продвинутое
- Лучшая история: <одна строка со ссылкой> или «нет»
```
Разногласие из раздела «Где источники спорят» не имеет номера заметки; ссылайтесь на url.

## В конце карты
- `## Главные споры`: самые острые разногласия, кто на какой стороне (url) и от чего зависит ответ.
- `## Пробелы`: подтемы с малым числом данных и то, чего читатель ждал бы от курса, но не нашлось ни в одном источнике.

Все url переносите в точности как в заметках. Результат: `<workspace>/research/agreement-map.md`. Итоговое сообщение: число тем по уровням, главные споры по строке и пробелы.
